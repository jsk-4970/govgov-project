## 🔧 解決した技術的課題

### 課題1: エンドポイント不一致エラー

**エラー内容:**
```
Incorrect API endpoint used. The current endpoint can only serve traffic from "global" region,
but got "asia-northeast1" region
```

**根本原因:**
- Vertex AI Searchのデータストアは`global`リージョンに存在
- クライアント初期化時にロケーション固有のエンドポイント指定が必要

**解決策:**
```python
# ロケーションに応じたAPIエンドポイントを設定
if location == "global":
    api_endpoint = "discoveryengine.googleapis.com"
else:
    api_endpoint = f"{location}-discoveryengine.googleapis.com"

self.client = discoveryengine.SearchServiceClient(
    client_options={"api_endpoint": api_endpoint}
)
```

### 課題2: モデルバージョン指定エラー

**エラー内容:**
```
Invalid version in model spec for summary: gemini-1.5-flash-001/answer_gen/v1
```

**解決策:**
モデルバージョン指定を削除し、デフォルトを使用

## ⚠️ 既知の課題

### データインポートの問題

**症状:**
- 検索実行は成功するが、意味のある回答が生成されない
- 「検索語句の要約を生成できませんでした」というメッセージ

**原因:**
- データストアにドキュメントは存在するが、内容が空（`Data keys: []`）
- JSONLファイルはGCSバケットに存在するが、正しくインポートされていない

**次のステップ:**

2. データの再インポート

## 🚀 使用方法

### CLIツールの実行

```bash
# 基本的な使用
python src/phase1/fact_check_cli.py "質問文をここに入力"

# 例
python src/phase1/fact_check_cli.py "デジタル庁の予算について教えてください"
```

### 環境変数設定（.env）

```bash
PROJECT_ID=govgov-473916
LOCATION=global
VERTEX_AI_SEARCH_DATA_STORE_ID=datastore-govgov_1759561195262
VERTEX_AI_SEARCH_LOCATION=global
```

### プログラムから使用

```python
from src.common.vertex_search_client import VertexAISearchClient
from src.common.config import AppConfig

# 設定読み込み
config = AppConfig.from_env(require_vertex_search=True)

# クライアント初期化
client = VertexAISearchClient(
    project_id=config.gcp.project_id,
    location=config.vertex_search.location,
    data_store_id=config.vertex_search.data_store_id
)

# 検索実行
result = client.search(query="質問文", max_results=5)
print(result["summary"])
```
